# PingPong Mouse Game

A classic PingPong game built with Python using Pygame.

## Description

This is a two-player PingPong game where players control paddles to hit a ball back and forth across the screen. The game features smooth controls, score tracking, and engaging gameplay.

## Requirements

- Python 3.7+
- Pygame

## Installation

1. Clone the repository:
```bash
git clone https://github.com/coderqueen67/PingPong-.git
cd PingPong-
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## How to Play

- **Player 1 (Left)**: Use `W` and `S` keys to move the paddle up and down
- **Player 2 (Right)**: Use `UP` and `DOWN` arrow keys to move the paddle up and down
- First player to reach 11 points wins!

## Game Features

- Two-player gameplay
- Real-time score display
- Ball physics with paddle collision detection
- Smooth paddle movement
- Game reset functionality (Press `R` to restart)
- Press `ESC` to quit
